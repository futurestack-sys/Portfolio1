# Alex Morgan | Student Developer

A responsive student portfolio built with semantic HTML5, CSS, and vanilla JavaScript.

## Sections
- Home / introduction
- About
- Education
- Skills
- Projects
- Achievements
- Contact

## Run locally
1. Download or clone this folder.
2. Open `index.html` in a modern browser.
3. For a local development server, open the folder in VS Code and use a local server extension if available.

No build tools, frameworks, or package installation are required.

## Personalize before submitting
1. Replace the sample name, introduction, school, program, dates, skills, projects, achievements, and email in `index.html`.
2. Use your own project descriptions and only claim achievements that are true.
3. If you add photos, use images you have permission to use and include meaningful alt text.
4. Test every navigation link, email link, and mobile menu.
5. Test at mobile, tablet, and desktop widths and in at least two browsers.

## Publish with GitHub Pages
1. Create a **public** GitHub repository for this website.
2. Upload the contents of this folder so `index.html` is in the repository root.
3. Open **Settings → Pages** in the repository.
4. Under the build/deployment source, choose **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)` folder, then save.
6. Wait for GitHub Pages to publish and copy the public URL shown in Settings → Pages.
7. Open that URL in a private/incognito window and on another device if possible.

## Accessibility and responsive design
- Semantic landmarks and a skip link
- Keyboard focus indicators
- Mobile navigation with `aria-expanded`
- Reduced-motion preference support
- Responsive layouts at 900px, 700px, and 480px breakpoints
- Responsive grid and flexible sizing to help prevent horizontal overflow

## Rubric preparation
Keep the source organized in `css/styles.css` and `js/main.js`. Be ready to explain the semantic HTML, CSS variables, responsive breakpoints, mobile navigation, and project layout during your defense.
